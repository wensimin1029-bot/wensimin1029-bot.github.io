# Shirley Wen — Portfolio

Bilingual personal portfolio with selected marketing work, career journey and project stories.

This is a buildless static website. GitHub Pages serves the `main` branch root. `.nojekyll` preserves the original static assets.

For local preview, run `python3 -m http.server 8765` in this directory, then visit http://localhost:8765.
